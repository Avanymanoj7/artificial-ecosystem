# 🌱 Artificial Life — Evolutionary Ecosystem Simulator

An advanced **Artificial Life and Evolutionary Ecosystem Simulator** built with **HTML, CSS, and JavaScript**.

The project simulates a dynamic ecosystem where herbivores, predators, and natural resources interact, compete for survival, reproduce, mutate, and evolve over time.

---

## 🚀 Project Overview

This project creates a virtual ecosystem containing:

* 🐄 **Herbivores:** Cow and Goat
* 🦁 **Predators:** Lion and Bear
* 🌿 **Resources:** Leafy Vegetables, Trees, and Greenery

Each organism has its own **genome, energy, lifespan, speed, vision, size, reproduction rate, aggression, and efficiency**.

The ecosystem changes continuously based on environmental conditions and interactions between organisms.
